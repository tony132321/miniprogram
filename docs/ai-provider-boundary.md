# AI 草稿提供方接入边界（本地契约）

当前生产小程序仍使用规则提取；本文件记录 `src/ai-provider-boundary.ts` 已验证的提供方无关执行契约。测试环境可向现有 `/events/drafts:suggest-local` HTTP 路由注入合成提供方，小程序能显示“未经核验”的生成建议。生产启动会拒绝注入提供方；尚未配置真实供应商或产生模型调用，不能作为 T10/T11 的真实模型验收。

T30 的合成动作审批、事务回执与当前活动公告上下文见 [AI 动作协议](ai-action-protocol.md)。该协议的 HTTP 测试夹具在开发及生产环境均关闭。

## 调用与预算

- 业务调用方必须显式提供本次草稿预算，单位为整数分；代码不把 PRD 的“每场 1 元”建议当作已批准的配置。预算未足够覆盖提供方声明的**单次保守成本上界**时，不发起调用。
- 提供方实现 `estimateUpperBoundFen(text, correction)` 与 `generate(text, { signal, correction, at })`。`at` 是服务端注入的日期锚点；`signal` 在最迟 30 秒的总期限到达时中止。服务端即使遇到不理会中止信号的提供方，也返回规则降级。对结构无效但已知费用的首答，剩余预算允许时最多纠错一次；费用未知时不再重试。
- 草稿原文先在服务端校验，空白或超长输入不会占用提供方请求键或产生费用不确定告警。已有键的不同原文仍返回幂等冲突。发送给提供方的文本会裁剪连续数字及常见空格、括号、点号写法的中国大陆手机号；本地规则提取仍基于原文。更广泛的隐私字段裁剪需要在真实提供方的数据处理评审中核定。
- 提供方返回的费用必须是非负整数分，且不得超过事前成本上界。测试环境的提供方调用先以用户与幂等键写入 `ai_draft_requests`，完成后保存响应、预算、提供方报告费用与费用可信状态。同一用户、同一键和同一原文重试只重放已完成结果；处理中、异常中断或不同原文重试返回 409，不再调用提供方。崩溃后遗留的 `STARTED` 记录需要运营核对，不能自动重试。
- `providerCostStatus=KNOWN` 表示已收到符合契约的提供方费用；`LOWER_BOUND` 表示先前尝试的已知费用下界，后续尝试超时或失败；`UNKNOWN` 表示无法确认费用。`known_cost_fen` 不能当成供应商账单。真实提供方的计费上界、供应商账单核对、每场累计预算及异常记录处理仍需在供应商选定后完成。
- 运营后台通过 `JOBS` 权限只读查看超预算、降级、费用不确定及遗留请求。列表只返回账号、请求键、状态、预算与费用线索；不返回草稿原文、哈希或建议结果。分页使用快照，期间列表变化时要求从第一页重新读取。发现异常不代表已查明供应商账单，也不会自动恢复或重试。

## 草稿事实

- 服务端规则能从原话确定的城市、日期、人数和费用上限优先于模型冲突输出。模型只可建议白名单字段；`venueStatus`、`hostParticipates`、报名与成局截止、付款状态不能由模型代主办确认。
- 模型提出的场馆名称和其他新增字段标为 `NEEDS_CONFIRMATION`，响应携带 `AI_GENERATED_UNVERIFIED` 标签；缺少真实库存与场馆接口时，不能把地图或模型名称当成已预约。
- 此契约只生成建议，不创建活动、报名、通知或付款，也不授予模型业务动作权限。发布仍使用已有的本人逐项预览、权限、版本和字段校验。

## 当前验证与待接入

`test/ai-provider-boundary.test.ts` 使用合成提供方验证：冲突字段优先级、场地待确认、手机号裁剪、最多一次纠错、预算不足不调用、预算不足不重试，以及提供方永不返回时按短测试期限中止信号并返回规则降级。`test/ai-provider-http.test.ts` 验证测试环境鉴权路由、无效输入不占用请求键、同键重放、并发抑制和生产禁用，`test/miniprogram.test.ts` 验证客户端生成内容标识。本人数据导出包含本人的请求结果与费用状态，删除影响清单显示该类别数量。正式供应商名称、凭据位置、服务适用性与数据处理评审、成本上界、实际模型 HTTP 适配和真机模型体验均未确定。
