# RQ20 每场 AI 草稿预算（2026-09-28）

## 实现范围

测试环境的合成模型路径首次提取前建立服务端活动草稿；后续提取沿用其 ID。第 52 版迁移将请求记录关联活动，保留调用前预算预留额。每次新请求在数据库事务中锁定活动行，核对主办方与草稿状态，并按当前活动的已知费用及不确定预留额计算余额。相同请求键重放原结果，不新增模型调用。费用不确定时不释放预留额；预算不足时返回规则降级并列入运营异常。

运营 `JOBS` 权限可查看每场已知费用与费用不确定占额的分页汇总，以及带活动 ID 的异常请求。本人数据导出包含自己的活动 ID 与预留额；旧请求没有活动归属，不补造历史成本。
