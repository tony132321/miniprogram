# PG07 公告问答读取状态

活动页原先把 `/events/:id/content` 读取失败转换成空列表，可能让已有公告和问答看起来像从未发布。现在读取失败或无权时分别显示 `ERROR`、`FORBIDDEN`，并清除旧账号或旧请求留下的内容；只有服务端成功返回空列表才显示空态。失败页沿用活动刷新动作重试。

先添加页面测试并确认旧实现失败，随后验证网络失败、恢复后的真实空列表、正常内容、无权状态及旧数据清理。微信开发者工具 `0.3.11` 已通过 `compile_wxml pages/event/event.wxml`。独立本地代理只对公告问答 GET 返回 503 时，活动页保持正常读取其他数据，显示[加载失败与重试按钮](wechat-content-retry-error-2026-09-26.jpg)；恢复接口后实际点击按钮，运行时状态从 `ERROR` 转为 `EMPTY`，见[恢复后的空态](wechat-content-retry-empty-2026-09-26.jpg)。服务端直接读取同一活动公告问答为 `{"items":[]}`。测试服务已停止，临时代理已移除。

全量 `pnpm test` 通过 317/317；`pnpm typecheck` 和 `git diff --check` 通过。此验证覆盖本地模拟器的读取与恢复；真机断网和正式服务仍待验。
