# 第 66 版合成备份恢复演练（2026-09-29）

范围：RQ18、T32、T34 的代码层验证。使用当前 `LATEST_SCHEMA_VERSION=66` 的本地 PGlite 合成库，没有真实成员数据或生产备份。

- `test/local-backup.test.ts` 先通过真实活动发布、报名和授权接口建立测试记录，再建立一条待处理的通知 outbox 与对应站内通知。关闭源库后归档到新文件，在新目录恢复并以应用 `createDatabase` 重新打开；逐项核对活动、报名、审计、66 条迁移校验值、当前授权、授权历史及 outbox 的通知和任务状态。定向测试 4/4，通过时输出 `backupDurationMs=404`、`localRestoreAndReadbackMs=465`。
- `test/privacy-deletion-replay.test.ts` 在同一旧快照中存入另一名合成成员的有效报名、授权及待处理通知 outbox，再执行首位合成账号删除，将 fsync 删除标记写在快照外。恢复旧快照时强制重放标记；回读确认删除账号仍停用、执行与共享活动去标识记录仍存在、隔离期限没有被重复重放延长，同时另一名成员的报名、授权及 outbox 保持快照值。缺失标记源时恢复拒绝继续。定向测试 6/6，通过时输出 `localRestoreMarkerReplayAndReadbackMs=479`。
- 新增的 PostgreSQL CI 脚本断言覆盖第 66 版事务性系统业务事件触发器，包括外发状态、无活动举报、申诉、删除请求、脱敏列结构和事务回滚；结果以本候选远端 CI 独立运行为准。

以上毫秒数是各自一次开发机合成库测量，用于证明代码路径可执行，不是目标环境 RTO 承诺。此快照没有连续增量日志，不能测得或承诺生产 RPO≤15 分钟；目标部署的实际备份频率、隔离恢复、删除标记独立持久性及 RTO≤4 小时仍待具备正式基础设施后验证。`AC-BACKUP-RESTORE` 保持部分完成。
