# 开发身份通知授权建档：本地验证（2026-09-28）

前置：通知授权函数已要求真实存在且活跃的账号。开发者工具使用的 `X-Dev-User` 合成身份原本不一定有 `users` 记录，因此首次开启授权返回 404。

修复：仅在非生产环境启用 `DEV_AUTH`、请求携带匹配的合成身份，且授权说明版本有效并明确开启时，HTTP 路由以 `dev:<身份>` 建立缺失的合成账号。已有账号不被覆盖，撤回及无效版本不触发建档；生产启动仍禁止 `DEV_AUTH`。业务函数对不存在账号的直接授权仍返回 `ACCOUNT_NOT_FOUND`。

先新增 HTTP 拒绝／成功测试，旧实现中有效授权返回 404；修复后定向 6/6、`pnpm test` **526/526**、`pnpm typecheck` 和 `git diff --check` 通过。测试使用本机 PGlite 与合成身份。微信开发者工具模拟器在本次验证期间因 Mac 锁屏无法操作，未取得新的页面点击证据；正式 AppID、微信逐条订阅授权与真机仍未验证。
