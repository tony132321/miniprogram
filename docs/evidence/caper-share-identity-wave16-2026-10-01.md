# 邀请卡会话身份复核（2026-10-01）

Wave 15 代码审查复现了一个旧邀请码暴露路径：主办人的 `userId` 不变，但登录会话更新，或从正式登录切到同名开发身份时，邀请卡只比较裸 `userId`，仍可打开旧分享弹层、复制旧口令或复用已准备的微信分享路径。

邀请卡现在分别记录主办人 ID 和加载时身份。前者只用于与服务端 `event.hostId` 核对；后者包含登录模式、会话 token 与用户 ID，贯穿活动、安全状态、二维码绘制、分享意图、剪贴板回调及原生分享路径。身份变化后清除活动展示、口令、分享来源与弹层，要求重新读取服务端资格。刷新请求未返回时发生身份变化，也会清除已显示的旧口令。

定向测试先失败：同一主办人换会话仍得到带 token 的分享路径；登录切到同名开发身份仍看到旧口令；刷新期间换会话仍保留旧邀请卡。修复后运行 `node --import tsx --test test/miniprogram-caper-share.test.ts`，**10/10 通过**。本轮没有运行全量测试；微信原生分享投递、真机账号切换及正式域名链路仍待外部资源验收。
