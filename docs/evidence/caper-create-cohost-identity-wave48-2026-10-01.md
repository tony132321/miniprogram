# 发起页协办入口会话隔离（2026-10-01）

设计依据：`stitch_design_system_generator (2).zip` 中 `pg03_ai/screen.png` 的活动构思入口和 `caper_ai/screen.png` 表单「协办人与主理人设置」卡。R1 的「＋ 添加协办人」在编辑已发布活动时，进入同场活动主办工作台；新活动尚无可选择的成员，因此显示发布后再设置的说明。

原 `openCohostSetup()` 直接读取页面缓存 `editingEvent.id`。若登录会话已切换而发起页 `onShow()` 尚未来得及清理，旧活动 ID 仍能被送入新会话的活动路由。现在按钮先比对 `_shownIdentity` 与当前登录身份；不一致时停止迟到的本地建议，清空旧编辑状态并提示重新输入，不发生导航。当前身份下已发布活动的同场 `hostSection` 路由及新活动的说明保留。
