# 运营账号最小权限验证（2026-09-24）

新式 `OPS_ACCOUNTS_JSON` 要求每个账号提供非空、无重复、仅含已知值的 `permissions`。在本地生产模式 HTTP 测试中，分别给七名合成运营人员单独授予 `REPORTS`、`SAFETY`、`EVENT_REVIEWS`、`APPEALS`、`PRIVACY`、`CONTENT`、`RATE_LIMITS`：各人仅能读取自己的队列，其他六类读请求均返回 403；对应写接口对无关账号也返回 403，获授权账号能进入业务校验。更改账号权限后，旧会话的凭据指纹不匹配并被拒绝。

工作台测试覆盖一个队列返回 403 时仍加载其他获授权队列，并把被拒队列标为“无权限”而非“0 条”。旧开发账号和单账号配置保留兼容。此验证仅证明软件限权机制；真实人员权限分配、值守排班、高风险处置的独立复核和部署侧审计权限仍须单独验收。
