# R1 直接人工分钟本地验证（2026-09-25）

PRD 第 21.2 节把“每场直接人工分钟”列为护栏。迁移 11 增加不可变时间条目，运营人员通过独立 `SUPPORT_MINUTES` 权限记录活动、类别和 0–1440 的整数分钟，并查看最近 100 条记录；只读 `METRICS` 权限不能写入。服务端附上操作人和时间，并写入审计。相同幂等键重试不会重复计入；页面在不确定失败后保留同一键重试。零分钟是明确填写的记录，未填写仍视为缺失。

试点聚合报表仅统计名单内、非测试、已到开始时间活动的已记录分钟、条目数和有记录的活动数，始终标记 `PARTIAL`。该来源不能证明其他运营人员已经全部填报；没有小时单价、实际收入和其他成本，因此贡献利润仍是 `UNAVAILABLE`。记录错误目前保留原始条目，尚无更正操作，真实试点前需建立复核流程。

验证：`test/support-minutes.test.ts` 检查输入边界、事务回滚、幂等重放、权限隔离、服务端操作人、测试活动和名单外活动排除；`test/operator-ui.test.ts` 检查部分数据提示和不确定失败的重试键。全套 `pnpm test` 124/124 通过，`pnpm typecheck` 与 `git diff --check` 通过。本地 PostgreSQL 18.6 全新库 `irl_r1_test_support_minutes_20260925` 完成迁移 1–11、两连接池读写，输出 `supportMinutesCrossPool=true`。只读复审发现并推动 `METRICS` 与 `SUPPORT_MINUTES` 权限拆分，复核无剩余 P1/P2。以上本地自动化与数据库演练不等于真实人员的全量填报。
