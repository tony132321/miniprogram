# 发起页快捷日期与结束日期同步（2026-10-01）

对照用户提供的 `stitch_design_system_generator (2).zip` 内 `pg03_ai`、`caper_ai`、`pg04` 图稿及现有原生发起三态，选择了 FORM 中已接通的日期快捷按钮作窄修。原逻辑先选“本周六”再选“本周日”时，只更新开始日期；结束日期仍为周六，生成的活动起止时间倒置，需用户额外手动修复。

现有 `setStartDate` 在结束日期尚未设置、与原开始日期相同，或已早于新开始日期时，将结束日期随开始日期更新；仍有效的手动跨日结束日期保留。场地核实状态继续在日期变化时清除，发布前预览与后端校验照旧。

定向用例先复现周六→周日后结束日期停在周六（`test/miniprogram-caper-create.test.ts` 20 项中 19 过、1 失败），修复后发起相关三个测试文件 **24/24** 通过；`pnpm typecheck` 与 `git diff --check` 退出码 0。按用户要求未运行全量测试，也未新增微信开发者工具实点或逐像素证据。
