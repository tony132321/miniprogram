# 生产启动配置闸门（2026-09-25）

在 `NODE_ENV=production` 时，服务连接数据库前核对微信 AppID/密钥与至少两个独立运营账号。账号必须覆盖内容审核、举报结案，并为每位原处理人员安排另一位具申诉权限的复核人。缺项直接退出；开发模式仍可使用本地测试身份和旧单账号配置。

`test/startup.test.ts` 使用实际 `src/main.ts` 子进程验证：缺少或留空微信凭据、缺运营账号、仅一个账号、第二账号无申诉权限均在数据库连接前失败；独立权限配置通过该闸门后才报告缺少数据库地址。全量 `pnpm test` 为 152/152，`pnpm typecheck` 和 `git diff --check` 通过。此检查证明配置形状和复核人分离，不证明账号由真实人员持有、微信账号可登录、密钥有效、运营值守就绪或目标部署可用。
