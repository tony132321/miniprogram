# 通知授权账号边界：本地回归（2026-09-28）

`setConsent` 在开启授权前，现在要求账号记录存在且状态为 `ACTIVE`；不存在时返回 `ACCOUNT_NOT_FOUND`，不会写入授权或占用幂等键。撤回授权仍可在删除申请处理中执行。此前函数只拒绝已存在的停用账号，直接调用它可以给不存在的身份写入孤立授权记录。

先新增不存在账号的拒绝测试，旧实现中因“未抛错”失败；修复后该测试及相关通知测试 20/20 通过。合成测试中原本先授权、后插入账号的夹具已改为先建立账号。最终 `pnpm test` 525/525、`pnpm typecheck` 与 `git diff --check` 通过。以上只证明本地账号边界，不代表微信的一次性订阅授权或真实消息投递已经接入。
