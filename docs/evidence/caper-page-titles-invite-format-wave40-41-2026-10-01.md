# 页面标题与发现页邀请口令入口（2026-10-01）

对照用户提供的 39 屏 ZIP 后，城市选择、关于 Project IRL、开源许可与致谢三页的顶栏仍分别显示生成稿中的占位标题 `Edit Profile`、`Edit Profile`、`Expense Breakdown`。三页现在使用与页面内容一致的中文标题；页面布局、返回、更多菜单和分享入口保持现有绑定。此处修正了设计稿本身明显错置的标题，并非逐字复制该占位文本。

发现页的“打开邀请”此前只检查输入非空，明显不符合口令格式的文本也会跳到活动加载页。同页“先预览”和扫码已检查 32 位口令格式；现在三处复用同一格式规则。格式不符时留在邀请输入区提示“请输入活动邀请卡上的 32 位口令”，格式符合时才进入原有活动页，由服务端验证口令真实存在、未过期及访问资格。格式通过本身不代表邀请码有效。

定向验证：城市和个人信息页测试 **10/10**；发现页操作与邀请焦点测试 **6/6**；TypeScript `tsc --noEmit`、发现页 JS 语法和 `git diff --check` 均通过。三处标题仅改 WXML 文案；发现页仅改已有按钮处理逻辑及对应定向测试。未运行全量测试或最新 CI，本轮没有微信开发者工具实点、真机或 39 屏逐像素验收。
