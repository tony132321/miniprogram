# RQ05 / RQ10 变更活动后的邀请到期时间

主办方延长或缩短报名截止时，原实现更新活动版本和报名截止，却保留发布时的 `invite_expires_at`。因此延长后链接可能提前失效，缩短后链接还可能展示已结束招募的活动。现在 `changeEvent` 在同一条 `UPDATE events` 中更新新版本、规则和邀请到期时间；令牌本身保持不变，材料变更后原有的暂停招募与重新确认规则仍生效。

先新增测试并确认旧实现失败：报名截止从 11:30 延长到 11:45 时，数据库仍保留 11:30；修复后延长和缩短两种变更的持久邀请到期时间都与当前截止完全一致。全量 `pnpm test` 为 335/335，`pnpm typecheck` 与 `git diff --check` 通过。

微信开发者工具 0.3.11 的本地隔离活动把报名截止延长 15 分钟后，访客用原令牌打开同一活动的新版本，页面显示“活动变更后已暂停新报名，等待原参与者重新确认”。[模拟器截图](wechat-changed-invite-expiry-2026-09-26.jpg)。模拟器仅验证当前令牌可访问和暂停提示；延长/缩短后的精确到期值由数据库测试证明，未等待真实截止或做真机分享验收。
