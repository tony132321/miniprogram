# 协办授权有效期数据库时钟验证（2026-09-26）

主办授予单场协办权限时，服务端先以数据库时间判断有效期，最终插入时再次要求有效期晚于数据库当前时间。应用实例时钟偏快不会提前拒绝有效授权；在写入临界点过期时，不留下授权或审计成功记录。

新增测试模拟应用时钟偏快两小时、数据库时间保持正常，以及早期检查通过后数据库时间在插入时跨过有效期。`pnpm typecheck` 通过，`pnpm test` 352/352 通过，独立代码审查无可执行问题。临界点测试采用 PGlite 时钟模拟，尚需目标 PostgreSQL 环境验证真实多实例与时间竞争。
