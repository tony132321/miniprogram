# RQ05 邀请换链截止由数据库裁定

主办方撤销旧邀请、生成新链接原先按应用时间检查报名截止，并在最终令牌更新中未重新检查。现在先用数据库时间判断，再在 `UPDATE events ... RETURNING` 检查仍在招募且报名窗口未关闭。过期换链不会改令牌、记审计或保存幂等成功结果。

先新增两个失败测试：数据库时间已过报名截止而应用时间仍早；检查通过后、最终令牌更新前窗口关闭。旧实现均会错误换链，修复后均拒绝。全量 `pnpm test` 通过 334/334，`pnpm typecheck` 与 `git diff --check` 通过。

微信开发者工具 0.3.11 在本地开发 API 中以主办方打开邀请活动，运行页面 `rotateInvite` 方法后回读新口令与“旧邀请已撤销，分享卡已更新”；服务端旧链接返回 404，新链接返回 200。[模拟器截图](wechat-invite-rotation-db-clock-2026-09-26.jpg)。截止竞态由数据库测试覆盖，未用演示时间冒充真实等待或真机分享验收。
