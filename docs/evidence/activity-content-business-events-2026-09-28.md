# 活动内容与站内通知事件补充（2026-09-28）

R1 指标 §21.4 需要服务端可核对的成功动作事件。第 55 版沿用现有 `audit` 同事务触发器，为带活动 ID 的内容提交、事实问题待办、内容审核及站内通知首次打开增加脱敏事件；迁移之前的记录不回填，以免把旧操作伪装成当前时间或当前版本。

事件只含活动 ID、活动版本、测试标记、动作名、时间、来源与加盐后的操作者摘要；不复制问题、回答、公告正文、驳回理由或通知内容。`CONTENT_*` 表示提交待审，不代表已展示；`MODERATE_*` 表示审核动作，不透露结论理由；`OPEN_NOTIFICATION` 表示站内首次打开，不表示微信消息已送达。通知在同一账号以不同请求键重复打开时只更新首次状态并产生一条事件。
