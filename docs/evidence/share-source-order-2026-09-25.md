# 分享来源先记录再展示卡片（2026-09-25）

主办方现在先主动点击“准备分享卡并记录来源”；服务端确认保存 `share_intents` 后，小程序才显示带该来源的“主动分享邀请卡”。分享回调只同步读取已经确认保存的来源，不再边返回卡片路径边异步写入来源。准备失败时不显示带来源的分享按钮；风险暂停或停止招募时只返回普通首页分享路径。准备分享卡仅表示主办方意图，不表示微信实际发送、对方收到或阅读。
