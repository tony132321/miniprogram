# PG08 动态签到码生命周期回归（2026-09-27）

范围：`miniprogram/pages/event/event.js` 的动态签到码展示及自动刷新。此证据来自本地小程序页面脚本测试，不代表微信开发者工具或真机验证。

## 先复现

- 延迟的取码响应在页面隐藏后仍把 `signed-token` 写入展示状态；新增用例首次运行退出 1，期望空值、实际为 `signed-token`。
- 旧码过期后发起下一次取码，等待新响应期间仍展示 `expired-token`；新增用例首次运行退出 1，期望空值、实际为 `expired-token`。
- 独立审查发现服务端计算的剩余秒数曾在慢网络响应后重新计时；新增跨过剩余有效期的用例首次运行退出 1，实际仍展示 `already-expired`。

## 修复与验证

- 页面隐藏、卸载或活动刷新时废弃未完成的取码请求、清除展示口令和刷新计时器；晚到响应与旧计时器不得重开二维码。只允许当前活动、版本、身份和签到管理权限下的响应更新页面。
- 请求替换口令时立即移除旧口令；响应到达后才展示新口令和安排下一次刷新。
- 客户端从发出请求时开始扣减网络耗时，并额外留出 1 秒服务端向上取整余量。响应抵达时已无可安全展示的有效期，就保持二维码隐藏，稍后重取。
