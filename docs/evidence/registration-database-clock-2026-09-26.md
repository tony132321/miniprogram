# 报名截止数据库时钟验证（2026-09-26）

正式报名和“暂不确定”意向的早期截止判断现在使用数据库 `clock_timestamp()`，避免某个服务实例的时钟偏快时提前拒绝。最终 INSERT/UPDATE 仍独立以数据库时间检查报名截止和邀请有效期，因此临界点竞争不会越过截止线。
