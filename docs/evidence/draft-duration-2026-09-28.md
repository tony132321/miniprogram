# RQ02 明确时长的草稿解析（2026-09-28）

## 范围

沿用已有一句话草稿规则降级路径。输入包含可定位的活动城市与开始时间，并明确说出“打两小时”时，草稿将结束时间设为开始后两小时，字段来源标为 `USER_EXPLICIT`。若缺少城市，开始与结束时间仍留空，要求主办方填写具体日期时间。发布前的其他字段确认与校验仍由既有业务接口执行。

后续补强：缺少城市但明确“三小时”时，规则仍将 180 分钟作为原话给出的草稿时长保留，不猜日期；用户选定日期后，创建页按当前开始时间推算结束时间，手动调整结束时间后不再自动覆盖。该时长随草稿保存，重新打开时仍可用于选择日期；若原话明确每人费用，上限不会因时长建议而在重新打开时清空。活动正式发布时仍移除仅供填表的时长建议。
