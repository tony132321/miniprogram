# 运营台过期会话边界（2026-10-01）

范围：v3.1 T30 `AC-UI-PG12` 的失效会话与跨运营账号页面隔离；沿用现有 `operations/index.html` 和 `src/operator-auth.ts`，未改服务端权限规则。

根因：服务端对过期或轮换后的运营令牌返回 `UNAUTHENTICATED` 401，运营台原先把它当普通读取或写入失败。刷新虽清除了多数队列，却保留会话存储、公开／全局止损状态、部分私有结果及可操作按钮；异步响应的 JSON 读取也可能在切换账号后才完成。

修复：所有运营请求统一识别 401，当前请求身份仍匹配时清除令牌和私有工作台、禁用工作台控件并提示重新登录；迟到的旧请求及其延迟 JSON 结果不再清除或显示到新会话。异步网络或 JSON 读取失败后也会复核请求身份，旧会话错误不会覆盖新账号的状态。并发登录只接受最后一次登录意图；退出登录会取消尚未返回的登录响应。重新登录并成功刷新后恢复控件。单个队列 403 仍显示“无权限”，网络故障仍可刷新重试且保留会话。

定向验证：覆盖当前令牌读取 401、写入 401、旧会话迟到 401、延迟旧写入结果、并发登录、登录与退出交错、旧写入网络及 JSON 错误；新增竞态用例在修复前 **0/5**，修复后 **5/5**。`node --import tsx --test --test-isolation=none --test-concurrency=1 test/operator-ui.test.ts` **56/56**、`tsc --noEmit` 和 `git diff --check` 通过。未运行全量测试；未在真实运营账号、浏览器会话或目标部署环境验证。
