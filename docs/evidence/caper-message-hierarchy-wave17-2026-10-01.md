# CAPER 消息页最近会话层级（2026-10-01）

参照用户 Stitch ZIP 中 `caper_3/screen.png` 与 `code.html`：最近会话区位于活动状态等通知分组之前。原小程序把“最近会话 · 尚未开放”卡排在全部通知组及“加载更多”之后，非空队列首屏无法看到这一设计层级。

现有关闭态卡已移到真实通知分组之前，仅在消息数据已加载且选择“全部消息”时显示。它仍明确写明私聊未开放，按钮继续进入已有的 `CHAT_UNAVAILABLE` 状态视图；没有添加原稿中虚构的头像、对话、未读数或后台私聊能力。活动／互动／系统筛选仍只展示对应真实通知。调整卡片最小高度、背景和下方间距以容纳前置位置。

新增层级与按钮定向用例先在旧顺序失败，修正后与消息相关 4 个定向文件合计 **44/44** 通过；类型检查与差异检查退出码 0。本轮未运行全量测试。此记录是源码与定向用例证据，尚未在开发者工具做消息页新布局截图或同尺寸逐像素验收。
