# AI 草稿提供方来源证据：合成适配器

v3.1 `specs/AI_ACTION_CONTRACT.md` 的测试集要求模型版本、提示词哈希、用量和脱敏回执。此处只验证测试环境注入的提供方契约，未调用真实模型。

## 本地契约

- 每次返回的合成模型结果必须包含非空模型版本、64 位十六进制 prompt hash、非负整数输入／输出 token 用量，以及状态和不透明提供方回执标识。服务端校验形状；元数据缺失或无效时降级为规则草稿，费用保持不确定，原预算预留不释放。
- 服务端只保存回执标识的 SHA-256 哈希，不保存原标识或自由文本回执。每次有效响应记录尝试序号、模型版本、prompt hash、用量、脱敏回执状态及报告费用。纠错调用留下两次记录。证据随现有 `ai_draft_requests.result` 保存并在同键重放时保持相同结果，无需迁移。
- `promptHash` 和 token 用量是适配器声明的数据；本地验证只能证明格式、持久化和重放，不能证明真实供应商计量或实际提示词内容。`providerCostStatus=KNOWN` 仍只表示契约内提供方报告费用，不是账单结清。

## 验证

`node --import tsx --test test/ai-provider-boundary.test.ts test/ai-provider-http.test.ts`：21/21 通过，覆盖原始回执不入结果、缺失来源数据时降级且费用不确定、两次调用分别记录、HTTP 持久记录及原有鉴权／预算／重放路径。独立复审补充了提供方返回 `REJECTED` 时不能显示模型生成结果的测试；该状态保留已报告的费用下界与全部预算预留，不视为供应商账单结清。

`pnpm typecheck`：本地执行通过；最终结果以根代理集成验证为准。

真实模型版本、实际 prompt hash、token 用量、供应商回执和账单均未接入或核对，不能据此宣称 RQ02/RQ20 的供应商验收完成。
