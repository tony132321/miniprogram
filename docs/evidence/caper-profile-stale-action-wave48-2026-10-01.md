# 个人页旧账号活动操作隔离（2026-10-01）

设计依据为 ZIP 的 `caper_1`「我的」页活动卡、邀请横幅和主理人工具。页面原先在账号或登录令牌切换后、下一次 `onShow` 刷新前，仍可用旧活动卡的 ID 打开活动详情或邀请卡；报名管理和主理人快捷入口也可能留下旧页面的导航意图。

现在这些依赖本人活动或个人状态的点击先使用个人页既有身份检查。发生切换时，旧通知和活动摘要立即清空、旧 ID 不导航；该旧页面在新身份资料成功刷新前不再接受这些操作。当前身份完成刷新后，原有活动、邀请、筛选和快捷入口保持可用。活动服务端仍执行自己的权限校验。

## 定向验证

- 在 `test/miniprogram-caper-profile-visual.test.ts` 用真实页面逻辑装载一场旧账号招募活动，切换到另一个用户与令牌后依次点击旧活动卡、邀请横幅、报名管理和主理人中心。新增用例在修复前失败，出现旧活动详情与邀请卡导航；修复后没有旧 ID 导航、没有导航意图写入，私有活动卡被清空。
- 同一文件包含当前身份正常活动、筛选和快捷入口验证，最终 **16/16** 通过；`tsc --noEmit`、`node --check` 和 `git diff --check` 通过。
- 本批未跑全量测试，也未做微信开发者工具或真机实点。该改动只封闭旧页面点击窗口，不代替服务端权限或正式账号验收。
