# 本机 HTTP 混合负载基线

`scripts/benchmark-http.ts` 只接受回环地址上名称以 `irl_r1_test_` 开头的空白 PostgreSQL 数据库。脚本用 20 个独立测试身份创建一场经人工审核的公开活动，启动真实 HTTP 服务，然后以目标 20 RPS 持续 30 秒：70% 读取活动详情、20% 读取本人活动列表、10% 新建草稿。每个请求经过 Bearer 会话校验和现有服务端限流；草稿写入使用独立幂等键。脚本读取全部响应，统计请求数、HTTP 错误和响应时延分位数。

2026-09-25 在本机 PostgreSQL 18.6 全新空库 `irl_r1_test_http_load_20260925` 上执行：600 次请求，实际 20.0 RPS，HTTP 错误 0，p50 4 ms、p95 6 ms、p99 7 ms。`pnpm typecheck` 与 `git diff --check` 通过；实例已停止。

这是单机回环网络、测试账号、单服务实例和 30 秒的基线，没有真实微信登录、TLS/反向代理、外部通知、AI 调用、目标服务器规格或 1 万注册用户的数据规模。它不能证明 PRD 的正式试点 p95≤800 ms 或月可用性 99.5%；部署后须按已确认的试点负载重新测量核心读写路径和故障场景。
