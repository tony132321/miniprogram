# Material Symbols report_problem source

The reference names the `report_problem` ligature. The pinned Material Symbols SVG directory returns 404 for this legacy name. This asset uses the official Google Fonts static subset at the reference axes instead. The retained font GSUB maps the exact character sequence `report_problem` to `uniE002`. The outline is exported without geometry edits; only the font coordinate system is flipped for SVG and the reference color applied. Source bytes and hashes are recorded in `source.json`. FontTools 4.60.2 SVGPathPen was used temporarily, without changing application dependencies. The official font version is 2.972; this separate source is not claimed to be the pinned SVG repository revision.
