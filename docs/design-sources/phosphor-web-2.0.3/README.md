# Phosphor web 2.0.3 source proof for discovery

The supplied `caper_4/code.html:38` pins `@phosphor-icons/web@2.0.3`. The exact npm package was fetched from the package's official registry entry, and both the tarball SHA-512 integrity and SHA-1 shasum were checked against `dist`. `registry-version.json` and `package-integrity.json` retain that evidence; `package.json` retains the package version and upstream repository. The CSS and TTF bytes for regular, bold and fill were extracted unchanged. The fonts internally report **Version 2.0**; that font name-table value is recorded separately from npm package **2.0.3**.

Nine glyphs are exported for the original header and four main cards only: bold magnifying-glass, funnel-simple and heart; fill compass, barbell, fork-knife and game-controller; regular calendar-blank and map-pin. Original mock status and shared bottom navigation glyphs are outside this task. `source.json` records each exact CSS Unicode selector, CSS definition line, original HTML node lines, font identity/version/hash, advance width, color, source CSS pixel size, complete SVG path hash and asset hash. The archived original HTML is `caper_4-code.html`; its SHA-256 is `514d9e5fbfbbc66e9c5c19cf33767b58b54f77a144720c4b89f3b5248356aed2`.

The original font em and advance width are 1024; hhea/typographic ascent is 960 and descent is -64. The exporter uses only `(1, 0, 0, -1, 0, 960)` to convert font coordinates into the original 1024-square line box. It does not redraw, simplify, substitute or crop the outlines. The SVG path contains the original regular/bold/fill form with the color of the matching source node. Page-local SVG assets are in `miniprogram/pages/discover/assets/`; TTF and CSS proof stays in this documentation directory and is never referenced by the mini-program.

The upstream MIT license is preserved verbatim at `docs/licenses/phosphor-web-2.0.3-MIT.txt`. Acquisition/export code is `export-source-glyphs.py`; export used FontTools 4.60.2 from the prior temporary dependency directory `/private/tmp/irl-material-symbols-wave60/fonttools` without changing that helper or dependency. It can be run with any environment that provides the same FontTools package; it reuses archived package bytes when the registry proof exists.

Primary source URLs: [fixed npm package metadata](https://registry.npmjs.org/@phosphor-icons/web/2.0.3), [fixed package tarball](https://registry.npmjs.org/@phosphor-icons/web/-/web-2.0.3.tgz), [upstream repository](https://github.com/phosphor-icons/web).
